# 蜂巢兵棋 · Hexwar

一个两人对战的六边形格子策略游戏，以及一个从零开始、靠自我对弈训练出来的 AI「宗师」。

- **在线试玩**：<https://pphy96826-coder.github.io/hexwar/>（第 44 代网络，随训练自动更新）（Chrome / Edge / Safari 18+，宗师需要浏览器支持 WebGPU）
- **游戏**：单个 HTML 文件，下载后用浏览器打开 `hexwar.html`（或 `index.html`）也能玩，不需要安装任何东西。
- **AI**：AlphaZero 式训练（神经网络 + 蒙特卡洛树搜索 + 自我对弈），网络在浏览器里用 WebGPU 运行，你思考时它也在后台思考。
- 讲解视频：[`video/hexwar_explainer.mp4`](video/hexwar_explainer.mp4)（规则 + AI 是怎么训练出来的）

## 规则速览

| | |
|---|---|
| 目标 | 打掉对方大本营（20 血）。双方同时归零时，场上单位总费用高的一方获胜 |
| 费用 | 每回合 +3/+4/+5 费（第 1–3 / 4–7 / 8 回合起），占领矿桥每回合额外 +1，上限 10 |
| 部署 | 只能放在与「连通区域」相邻的空格：从本方大本营出发、经由本方单位相连的格子。大本营周围 2 格内永远可以部署 |
| 先后手 | 先手方先部署，后手方看到后再部署；先手每回合轮换 |
| 结算 | 双方都结束部署后**同时**结算：一个单位受到的伤害 = 所有覆盖它的敌方单位伤害之和，≥ 血量就阵亡，可以同归于尽 |
| 克制 | 突击 → 远程 → 重装 → 突击，克制方伤害 +1；护甲减伤，穿透无视护甲 |
| 大本营 | 每回合对相邻敌人造成 2 点伤害；每损失 5 血获得 2 费（怒气） |
| 孤立 | 与大本营断开的单位攻击 −1，也不能当落脚点 |
| 决战 | 第 15 回合起所有单位攻击 +1 |

23 个兵种：民兵、剑士、骑兵（突进）、刺客（潜行）、狂战士（血怒）、盾兵、长枪兵、荆棘卫（反伤）、守护者（护甲光环）、攻城锤（只打大本营）、弓手、弩手（穿透直射）、游侠（破甲标记）、投石车（攻城×2）、火药桶（殉爆）、工兵（架桥筑路）、旗手（前哨）、骷髅兵（重生）、战鼓手、牧师、法师、伞兵（空降）、巨龙（飞行、唯一）。所有射程都朝向敌方大本营。

地形：森林（血+1，挡直射）、高地（远程攻击+1）、河流（只有工兵和巨龙能站）、矿桥（+1 费）、岩石（不可进入）。

地图：河谷、高原、峡谷三张固定地图，以及「随机生成」：每局一张新的中心对称地图，双方地形完全一样。

## 电脑难度

| 难度 | 做法 |
|---|---|
| 简单 / 普通 / 困难 | 手写规则 + 局面评估（评估权重用自我对弈调参） |
| 大师 | 在「整回合部署方案」上做蒙特卡洛树搜索，每步约 4 秒 |
| **宗师** | 神经网络 + 逐个部署的 PUCT 树搜索；局面判断一半来自网络、一半来自大师的威胁计算；用对手思考时间预先搜索 |

## AI 是怎么训练出来的

完整代码在 [`train/az/`](train/az)。

1. **规则就是模拟器**：训练直接加载 `hexwar.html` 里的游戏脚本（`train/engine.js`），保证训练和真实对局用的是同一套规则；`simEndRound` 与真实游戏逐回合比对一致（`consistency_test.js`）。
2. **局面编码**（`game.js`）：87 个特征平面（地形、双方各兵种、血量/攻击/护甲、覆盖范围、可部署格、费用、回合……），棋盘总是转到「当前行动方在下方」，所以一个网络同时会玩先手和后手。
3. **网络**（`model.py`）：全卷积残差网络（64 通道 × 6 层，约 52 万参数），对任何大小的地图都适用。输出：每个(兵种, 格子)的部署概率、结束回合的概率、胜率估计。
4. **搜索**（`mcts.js`）：每一步动作是「放一个兵」或「结束回合」，用 PUCT 搜索选择。
5. **自我对弈循环**（`train.py` + `selfplay.js`）：
   - 先模仿手写 AI 的 640 局，得到一个起点；
   - 每代：自我对弈 384 局（随机地图占多数，让它学会读地形而不是背地图）＋ 与大师对战 96 局 ＋ 与脚本进攻者对战 64 局；
   - 训练 1200 步；新版本与当前最强版本对打 40 局，胜率 ≥ 55% 才替换；
   - 每 3 代与手写大师打 48 局，衡量真实进步。
6. **从真人对局中学习**：在本地页面与宗师对战的每一局都会自动存成训练数据（`server.py`），每一批训练都混入玩家对局的局面。
7. **浏览器里的宗师**（`train/az/web/`）：
   - `nn.js`：WebGPU 计算着色器实现的网络推理（结果与 PyTorch 一致到 1e-5）；
   - `mctsweb.js`：批量 + 虚拟损失的树搜索，4 个 Web Worker 并行；
   - 思考时间利用：玩家部署时，AI 按「玩家现在就结束回合」的局面提前搜索；
   - `threat.js`：专门识别「铺一串工兵、把攻城锤送到大本营背后」的威胁——这是人类玩家反复击败 AI 的打法。

### 训练进展（只用网络、不混入手写评估，每步搜索 200 个局面，对手为手写大师）

| 代数 | 3 | 6 | 9 | 12 | 15 | 18 | 21 | 24 | 27 | 30 | 33 | 36 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 胜率 | 33% | 50% | 33% | 27% | 43% | 49% | 42% | 62% | 60% | 79% | 82% | **94%** |

第 21 代之后加入了：持续训练候选网络、与大师/脚本进攻者的对局、玩家对局数据、胜率目标与搜索估计的混合。宗师实战配置（网络 + 手写威胁评估）对大师 24:0。

## 自己训练

需要 Node.js 18+、Python 3.10+、PyTorch（Apple 芯片用 MPS，NVIDIA 用 CUDA）。

```bash
python3 train/az/train.py                 # 开始或继续训练（检查点和日志在 train/az/out/）
python3 train/az/server.py 8765           # 本地服务器：http://localhost:8765/hexwar.html 会自动加载最新网络并回传对局
train/az/run_forever.sh                   # 崩溃后自动重启训练
touch train/az/out/STOP                   # 当前一代结束后停止
python3 train/az/web/build.py hexwar_base.html models/net_best.bin hexwar.html   # 把网络打包进游戏页面
```

`models/` 里是当前最强的网络（第 44 代）：`best.pt`（PyTorch）和 `net_best.bin`（浏览器用）。
